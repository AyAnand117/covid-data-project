# COVID-19 Data Analysis Project

End-to-end data analytics project using Python, SQL Server, and Power BI.

## Tools Used
- Python
- Pandas
- SQL Server
- SSMS
- Power BI
- Git & GitHub

## Project Workflow
1. Raw COVID data collection
2. Data cleaning using Python
3. SQL Server data modeling
4. SQL analysis and views
5. Power BI dashboard creation

## Folder Structure

```text
data/
    raw/
    cleaned/

python/

powerbi/
docs/
```

## Key Features
- Automated data cleaning pipeline
- SQL analytical queries
- Country-wise COVID trend analysis
- Interactive Power BI dashboards
